# Cell Pattern Classifier Lab

## a. Problem statement

This project implements and compares five supervised classification models on one labeled dataset. It reports accuracy, AUC, precision, recall, F1 score, and Matthews correlation coefficient (MCC). The Streamlit app accepts a labeled test CSV and, after a valid file is uploaded, displays results for all five models, a model-selection dropdown, evaluation metrics, and a confusion matrix and classification report. It loads the saved models and never retrains on uploaded test data.

## b. Dataset description

The project uses the **Breast Cancer Wisconsin (Diagnostic)** dataset from the UCI Machine Learning Repository. It has 569 observations, 30 continuous features, and a binary `diagnosis` target (`B` = benign, `M` = malignant). The features are ten measurements of cell nuclei, each represented by its mean, standard error, and worst value. The original sample identifier is retained in `data/breast_cancer_wdbc.csv` for traceability and excluded from modeling.

The dataset exceeds the assignment minimum of 12 features and 500 instances. It contains no missing values. A fixed stratified holdout contains 455 training rows and 114 test rows; `test_data.csv` is the labeled CSV used by the app and metrics. Malignant (`M`) is treated as the positive class for AUC, precision, recall, and F1.

**Source and citation:** Wolberg, W., Mangasarian, O., Street, N., & Street, W. (1993). *Breast Cancer Wisconsin (Diagnostic)* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5DW2B. Dataset page: https://archive.ics.uci.edu/dataset/17/breast

## d. Models used

All five classifiers are trained with the same 455 training records and evaluated on the same 114 held-out records. Standard scaling is included inside the Logistic Regression, KNN, and SVM pipelines so the fitted preprocessing is saved with each estimator. The Decision Tree and Gaussian Naive Bayes use their native feature handling. The model settings and random seed are documented in `train_models.py`. Malignant (`M`) is treated as the positive class.

### Observations on model performance

The observations below summarize the results on the fixed 114-row holdout. AUC measures how well each model ranks examples across score thresholds, while precision and recall describe its predictions at the classification threshold.

| Decision Tree | The Decision Tree has the lowest AUC (0.8752), accuracy (0.8772), malignant recall (0.7674), F1 (0.8250), and MCC (0.7361) of the five models. Its precision is 0.8919, but its lower recall means it misses more malignant cases than the other models on this holdout. |
